Privacy Policy

pinstory · last updated 16 August 2026

pinstory is a personal, single-user tool built and operated by Spreadsheets Labs for the sole use of its owner. It has no other users, no sign-up, no public interface, and is not offered as a product or service to anyone else.

What it accesses

Using the owner's own Pinterest access token, with the scopes boards:read and pins:read, pinstory reads only the owner's own boards and pins. It does not read, request, or store any other Pinterest user's data.

What it stores

  • A file listing the owner's own pins: pin ID, board name, image URL, and alt text.
  • A file recording which of those pins have already been used.

Both files live in the owner's own private code repository. There is no database, no analytics, no tracking, no cookies, and no user accounts.

What it does with it

Every other day, pinstory selects five of the owner's own saved images, reformats each into a 1080×1920 vertical frame, and sends the results to the owner's own private Telegram chat. The owner then reposts them manually. Image extension is performed by Google's Gemini API, and only the owner's own images are sent for that processing.

What it does not do

  • It does not write, create, edit, or delete anything on Pinterest.
  • It does not collect data about any person other than the owner.
  • It does not sell, share, or publish data to any third party. The only services it contacts are Pinterest, Google Gemini, and Telegram, each solely to perform the function described above.
  • It serves no advertising and builds no user profiles.

Retention and deletion

All stored data is under the owner's direct control and can be deleted at any time by deleting the files. Revoking the Pinterest access token immediately and permanently ends all access.

Contact

Questions about this policy can be sent through spreadsheetsmusic.com.

This policy covers pinstory only. It does not describe the spreadsheetsmusic.com website itself, which collects no personal data.
